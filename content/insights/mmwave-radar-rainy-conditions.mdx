# 毫米波雷达可以在雨天使用吗？雨天水流速与水位监测说明

在河道、水库、山洪沟道和城市排水项目中，很多现场真正需要监测的时刻恰恰发生在降雨期间。因此，“**毫米波雷达可以在雨天使用吗**”是雷达水流速计、雷达水位计和户外在线监测系统选型时经常被问到的问题。

一般来说，毫米波雷达可以在雨天用于非接触式水文监测。它不需要接触水体，通常安装在桥梁、支架、岸边立杆或排水渠上方，通过发射和接收电磁波信号获取水面流速、水位或目标位移信息。小到中等降雨条件下，只要设备安装合理、防护设计可靠、回波质量满足算法要求，系统通常可以持续工作。

但这并不意味着降雨对测量完全没有影响。强降雨、暴雨、风浪、漂浮物、雨滴打击水面形成的复杂纹理，以及支架晃动等因素，都可能改变现场回波特征。工程上应把“雨天可用”理解为：设备具备在户外雨水环境中长期工作的基础能力，同时需要通过正确选型、安装和数据校核来控制误差。

## 为什么毫米波雷达适合雨天在线监测？

毫米波雷达的优势在于非接触式测量。设备通常位于水面上方，不需要浸入水中，也不容易被泥沙、水草、漂浮物或污水直接缠绕、腐蚀。对于暴雨期间不适合人工下水的场景，这一点非常重要。

在水流速监测中，雷达根据水面运动引起的多普勒频移估算表面流速；在水位监测中，雷达通过回波距离计算水面高度。因为测量链路主要发生在空气中，设备只需要保持雷达波束前方无遮挡，并使有效水面处于可测范围内。

这种方式适合以下雨天应用：

- 山洪预警断面的水位、流速变化监测；
- 城市排水渠、箱涵、泵站前池的暴雨过程监测；
- 中小河流、桥涵和灌溉渠道的在线水文采集；
- 水库泄洪、闸门调度和排涝工程的无人值守监测；
- 与雨量计、视频、水位计和云平台组成综合预警系统。

## 降雨会怎样影响雷达测量？

降雨影响主要不是“雨水会不会打坏雷达信号”这么简单，而是多个现场因素共同作用。

| 影响因素 | 可能表现 | 工程处理建议 |
| --- | --- | --- |
| 小雨或中雨 | 水面回波通常仍可用于测量 | 保持正常监测，并关注数据连续性 |
| 强降雨或暴雨 | 水面波纹、雨滴扰动和浪涌增多 | 结合水位、雨量和历史数据进行判断 |
| 大风伴随降雨 | 支架晃动或水面风浪增强 | 加固安装结构，避免设备方向变化 |
| 漂浮物和泥沙 | 回波区域可能出现短时异常 | 选择主流区并设置异常值过滤策略 |
| 桥梁或栏杆遮挡 | 雷达波束被局部遮挡 | 调整安装位置和俯仰角 |
| 设备进水或接插件受潮 | 通信中断或长期可靠性下降 | 关注外壳防护、线缆密封和防雷接地 |

对于雷达水流速计而言，雨滴可能改变水面微纹理，使表面回波更复杂；暴雨洪水时水面还可能出现泡沫、漂浮物、浪涌和局部回流。因此，雨天数据应结合现场断面、安装角度和水位变化趋势综合判断，而不应只看单个瞬时速度值。

## 雨天使用时，安装位置比参数更关键

很多测量问题并不是由雷达频段本身造成的，而是由现场安装条件引起的。雨天应用尤其要重视安装位置。

### 选择稳定可观测的水面

雷达波束应对准稳定的有效水面，尽量避开岸边死水区、桥墩回流区、闸门强紊流区和漂浮物长期堆积的位置。对于渠道和河道，应优先选择能够代表主流流态的区域。

### 保证支架和横臂刚性

暴雨常伴随大风，支架晃动会直接改变雷达指向。设备支架、横臂、抱箍和基础应具备足够强度，长期无人值守项目还要考虑锈蚀、振动和人为碰撞。

### 避免雷达波束遮挡

桥梁栏杆、电缆、树枝、监控杆件和临时施工设施都可能进入雷达视场。雨天水位上涨后，原本安全的测量区域也可能被漂浮物或结构物干扰，因此安装前应评估不同水位下的视场。

### 配合水位和雨量数据

雨天流速变化通常与水位上涨、降雨强度和汇流过程有关。单台流速计可以提供关键数据，但在预警和调度项目中，更推荐“流速 + 水位 + 雨量 + 平台阈值”的组合。

## AR-FV100 类雷达水流速计在雨天选型要看什么？

以 AR-FV100 毫米波雷达水流速计这类非接触式设备为例，选型时应关注现场是否匹配其测量范围和安装条件。常见项目会关注 24 GHz 雷达、0–20 m/s 测速范围、±0.2 m/s 精度、0.5–30 m 测量距离、7–28 V DC 供电、IP68 防护，以及 RS485、RS232、4–20mA 等可按项目配置的输出方式。

这些参数需要与具体工况结合判断：

| 选型项目 | 雨天关注点 |
| --- | --- |
| 测速范围 | 暴雨洪水期间最大流速是否超出设备范围 |
| 测量距离 | 高水位和低水位时设备到水面的距离是否都在有效范围内 |
| 防护等级 | 外壳、接插件、线缆和安装盒是否适合长期户外雨水环境 |
| 输出接口 | 是否便于接入 RTU、PLC、采集仪或云平台 |
| 供电方式 | 太阳能和电池容量是否能覆盖连续阴雨天 |
| 数据策略 | 是否支持异常值过滤、阈值告警和远程诊断 |

## 哪些雨天场景需要谨慎评估？

虽然毫米波雷达适合户外非接触式监测，但以下场景需要谨慎评估，必要时进行现场试测：

1. **极端暴雨和洪峰过程**：水面紊动剧烈，漂浮物密集，局部流态变化快。
2. **封闭或半封闭箱涵**：安装空间狭窄，雷达波束可能被侧壁、顶板或管线干扰。
3. **水面过于平静或过于破碎**：回波特征不足或异常复杂，都会影响数据稳定性。
4. **支架难以固定的临时点位**：风雨环境下方向变化会放大误差。
5. **供电通信薄弱的山区点位**：连续阴雨可能导致太阳能供电不足，通信质量也可能下降。

这些问题并不代表不能使用雷达，而是提醒项目设计应包含现场踏勘、安装结构设计、数据校核和维护策略。

## 雨天监测项目的推荐配置

对于山洪预警、城市排水和河道在线监测，建议从系统角度配置设备，而不是只购买单台传感器。

- 前端传感器：雷达水流速计、雷达水位计、雨量计，必要时增加视频或水质设备；
- 安装结构：立杆、横臂、桥梁支架、防雷接地和线缆保护；
- 供电通信：市电、太阳能、电池、4G/NB-IoT/有线网络等；
- 数据平台：实时曲线、阈值告警、历史报表、远程设备状态和 API 接入；
- 运维机制：定期巡检、雨季前检查、异常数据复核和备件管理。

## 常见问题

### 毫米波雷达雨天还能测流速吗？

通常可以。小到中等降雨条件下，非接触式毫米波雷达水流速计仍可用于水面流速监测。但暴雨、浪涌、漂浮物和安装晃动可能影响数据稳定性，需要结合现场工况判断。

### 暴雨会不会让雷达完全失效？

不一定。暴雨更常见的影响是回波质量变化、流态复杂和短时异常值增加。合理安装、防护、供电通信和数据过滤可以提高可用性，但极端工况仍建议进行现场验证。

### 雨天监测只装流速计够吗？

多数预警或调度项目不建议只依赖单一流速数据。更稳妥的方案是组合水位、雨量、断面参数和平台阈值，形成完整的在线监测系统。

### 雷达设备需要雨棚吗？

户外雷达设备通常应具备相应防护能力，但雨棚或防护罩是否需要取决于设备结构、安装位置和现场环境。应避免雨棚遮挡雷达波束或形成积水滴落干扰。

### 连续阴雨对无人值守站点有什么影响？

连续阴雨可能影响太阳能充电和通信稳定性。因此需要核算电池容量、功耗、通信策略和数据补传机制，确保站点在雨季仍能持续运行。
